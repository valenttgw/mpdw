Uji Formal

# Normalitas
ks.test(sisaan, "pnorm", mean(sisaan), sd(sisaan)) 
## 
##  Exact one-sample Kolmogorov-Smirnov test
## 
## data:  sisaan
## D = 0.062712, p-value = 0.8918
## alternative hypothesis: two-sided
# H0: Menyebar normal

# Kebebasan Sisaan
Box.test(sisaan, type = "Ljung") 
## 
##  Box-Ljung test
## 
## data:  sisaan
## X-squared = 0.0016914, df = 1, p-value = 0.9672
# H0: Sisaan saling bebas (tidak ada autokorelasi)

# Kehomogenan Ragam
Box.test(sisaan^2, type = "Ljung") 
## 
##  Box-Ljung test
## 
## data:  sisaan^2
## X-squared = 1.1854, df = 1, p-value = 0.2763
# H0: Ragam sisaan homogen

# Nilai Tengah = 0
t.test(sisaan, mu = 0, conf.level = 0.95) 
## 
##  One Sample t-test
## 
## data:  sisaan
## t = 0.09028, df = 79, p-value = 0.9283
## alternative hypothesis: true mean is not equal to 0
## 95 percent confidence interval:
##  -0.3950593  0.4325989
## sample estimates:
## mean of x 
## 0.0187698
# H0: Nilai tengah sisaan sama dengan nol

Berdasarkan pengujian formal di atas, seluruh asumsi model terpenuhi dengan baik:

Normalitas: Uji KS menghasilkan p-value = 0.8918 > 0.05, gagal tolak H0 (Sisaan menyebar normal).

Kebebasan Sisaan: Uji Ljung-Box menghasilkan p-value = 0.9672 > 0.05, gagal tolak H0 (Sisaan saling bebas / tidak ada autokorelasi).

Kehomogenan Ragam: Uji Ljung-Box untuk sisaan kuadrat menghasilkan p-value = 0.2763 > 0.05, gagal tolak H0 (Ragam sisaan homogen).

Nilai Tengah Sisaan: Uji-t menghasilkan p-value = 0.9283 > 0.05, gagal tolak H0 (Nilai tengah sisaan sama dengan nol).
